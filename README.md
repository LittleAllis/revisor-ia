# Revisor de datos sensibles para IA

Extensión gratuita para Chrome y Edge. Detecta y enmascara datos sensibles, como correos, cédulas, tarjetas y contraseñas, antes de que se envíen a ChatGPT, Gemini, Copilot o Claude. Todo el análisis ocurre en el navegador: el texto nunca sale de tu equipo.

**Página y descarga:** abre la página de este repositorio en GitHub Pages y pulsa **Descargar extensión**.

## Instalación
1. Descomprime `revisor-ia-extension.zip`.
2. Abre `chrome://extensions` (en Edge, `edge://extensions`) y activa el **Modo de desarrollador**.
3. Pulsa **Cargar descomprimida** y elige la carpeta `revisor-ia-extension`.
